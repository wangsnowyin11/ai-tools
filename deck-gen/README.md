# DeckGen

A local previewer and editor for HTML slide decks. No API key needed: decks are generated by Claude outside the tool and saved into `decks/`. The tool keeps them in sync, previews them, and lets you edit and present them.

## Run

```bash
cd ~/Cowork/deck-gen
npm start            # or: node server.js   (Node 18+, nothing to install)
```

Open http://localhost:5173.

## Where decks come from

Every deck is a `.html` file in `deck-gen/decks/`. You can get one there in any of these ways:

* **Ask Claude in Cowork:** for example, *"Make a deck from this doc following `deck-gen/prompts/system.md` and save it to `deck-gen/decks/my-design.html`."* To change it later: *"In `decks/my-design.html`, tighten slide 4."*
* **Save from any Claude chat:** save the reply into `decks/`.
* **Paste HTML:** copy the reply, then click **Paste HTML** in the tool.
* **+ New / Import…:** start from the empty template, or bring in an existing `.html` deck.

Full HTML documents and slide-only `<section>` output both work. Slide-only files are wrapped in the deck template automatically.

## How sync works

```
 Claude / any editor ──writes──▶ decks/x.html ◀──autosave (0.7s)── tool editor
                                     │
                     server watches folder (fs.watch)
                                     │ push event (Server-Sent Events)
                                     ▼
                 tool re-reads the file → editor + preview update
```

* **Disk → tool:** when a file in `decks/` changes, open tools reload it and stay on the current slide. If you have unsaved edits, you're asked first.
* **Tool → disk:** edits autosave to the same file. ⌘/Ctrl+S saves immediately.

## Select mode

Click **⌖ Select**, or press **S**, then click anything in the preview. The editor highlights that element's HTML and scrolls to it. A breadcrumb (`section.slide › div.cols › div.card › h3`) lets you select a parent instead. Clicking anywhere inside a diagram selects its `<pre class="mermaid">` source. Press **Esc** to exit.

## Deck format

* Each `<section class="slide">` is one slide, preceded by a `<!-- ===== SLIDE N: … ===== -->` separator.
* Slides sit between `<!-- SLIDES:START -->` and `<!-- SLIDES:END -->`. **Paste HTML** replaces only what's between them, so your theme edits are kept.
* Diagrams are Mermaid source inside `<pre class="mermaid">`. Rendering them needs internet, because Mermaid loads from a CDN.
* Restyle the deck in the `:root` variables at the top of the `<style>` block.
* Downloaded decks work on their own: arrow keys to navigate, **F** for fullscreen, and print to PDF exports one slide per page.

## Files

* `decks/`: your deck files, which the tool watches.
* `prompts/system.md`: the generation guidance and HTML building blocks to give Claude.
* `public/template.html`: the deck theme, layout, and navigation.
